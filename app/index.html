    Languages

    Every name and every note uses one of these languages. If a language is missing, ask an administrator to add it.

      Types

      Every place, border and route has one of these types; the type decides its marker, line or colour on the map. If a type is missing (iron mine, cedar forest, sword artefact, a kind of border or route), ask an administrator to add it.

        Categories

        Categories group the layers (Layers tab).

          Borders of countries, regions and other areas, and lines. Colour them, make them transparent and show their names on the map. They can belong to layers and follow the period filter of Explore.
